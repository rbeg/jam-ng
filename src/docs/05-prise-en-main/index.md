# Prise en main des outils

Cette section s'adresse à tous — développeurs, ops, product managers — qui veulent
être autonomes sur la plateforme d'observabilité au quotidien.

L'objectif n'est pas d'être exhaustif sur chaque fonctionnalité de Kibana. C'est de
répondre aux questions pratiques les plus fréquentes : où chercher, comment filtrer,
comment lire une trace, comment investiguer un incident.
