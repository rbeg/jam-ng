# Kibana › APM

## À quoi sert Kibana APM ?

APM est l'interface Kibana dédiée à l'analyse des performances applicatives. Elle
présente de façon structurée les données collectées par les agents APM : services,
transactions, traces distribuées, erreurs, métriques JVM.

C'est l'outil de référence pour investiguer une dégradation de performance, identifier
la dépendance en cause dans un appel distribué, ou analyser la fréquence et l'impact
d'un type d'erreur.
