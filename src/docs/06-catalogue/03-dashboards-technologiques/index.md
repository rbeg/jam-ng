# Dashboards technologiques

Les dashboards technologiques couvrent les **briques techniques transverses** utilisées
par plusieurs équipes. Ils sont maintenus par l'équipe plateforme et évitent que chaque
équipe crée son propre dashboard pour un même besoin.

Tous ces dashboards sont filtrables par équipe ou par composant.
