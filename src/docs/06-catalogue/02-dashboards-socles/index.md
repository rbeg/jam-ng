# Dashboards socles

Les dashboards socles sont **maintenus par l'équipe plateforme** et disponibles pour
tous les services. Ils couvrent les besoins universels de supervision et constituent
le point de départ pour toute investigation.

Tous ces dashboards sont paramétrables via les filtres `service.name` et
`service.environment`.
